**來源資訊**：
- URL: https://www.binance.com/en/trade/BTC_USDT
- 檢查日期: 2026-10-27
- 平台/地區: Binance Global / Pro Mode
- Desktop/Mobile: Desktop (1440×900)
- 來源類型: Public（無需登入可觀察基本佈局）

**直接觀察**：
- 三欄佈局：左側觀察名單（約 15%）、中央圖表（約 55%）、右側訂單面板（約 30%）
- 頂部固定列：交易對選擇、價格顯示（大字體 24px+）、24h 漲跌幅

**推論**：
- 觀察名單可自定義（基於 UI 的 + 按鈕）
- 圖表支援指標疊加（基於工具列圖示）
- 訂單面板可能有更多進階選項（基於「Advanced」按鈕）

**無法確認**：
- 實際可調整比例（需登入測試）
- 快捷鍵支援（需登入測試）
- 持倉詳情（需登入）

**對 Alethra 的啟示**：

- 訂單面板應獨立且功能完整

## 對 Alethra 的具體啟示總結

### 資訊架構

1. **三欄佈局是專業標準**：Binance、TradingView、富途都採用左側觀察名單、中央圖表、右側訂單/持倉
2. **圖表應佔主導**：60-70% 寬度，強調分析功能
3. **Widget 系統可選**：Robinhood Legend 提供可定制佈局，但增加複雜度
4. **持倉與交易日誌整合**：富途、Robinhood 都將兩者關聯顯示

### 視覺設計

1. **深色主題為主**：Binance、TradingView、富途都提供深色主題
2. **價格突出顯示**：大字體（24px+）、漲跌幅用顏色區分
3. **術語一致**：各平台都使用統一術語（持倉、訂單、成交）
4. **狀態明確標示**：訂單狀態、數據延遲、模擬/即時模式

### 功能設計

1. **觀察名單可自定義**：用戶可新增/刪除標的
2. **訂單面板功能完整**：支援多種訂單類型（限價/市價/止損）
3. **快捷鍵提升效率**：專業平台通常支援快捷鍵
4. **Layout 保存**：允許用戶保存並切換不同佈局

### 文案設計

1. **中文優先**：富途、SoFi HK 都使用繁體中文
2. **術語統一**：「持倉」不混用「倉位」「部位」
3. **具體勝過抽象**：「買入 100 股」而非「確認」
4. **風險提示明確**：模擬交易必須標示「模擬」
