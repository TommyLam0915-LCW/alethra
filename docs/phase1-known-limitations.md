# Phase 1 已知限制

**日期**: 2026-10-11
**引擎版本**: 1.1.0

---

## 技術限制

### 資料

- 僅支援日線（1d）OHLC 資料
- 僅支援美股市場（示範資料為模擬）
- 不處理股息、配息、除權、股票分割
- 不處理停牌、漲跌停、流動性不足
- 示範資料日期範圍固定（2024-01-02 ~ 2024-02-14）

### 策略

- 每次回測僅針對單一資產（不支持多資產組合）
- 僅支援做多，不支援做空或融券
- 不使用保證金或槓桿
- 假設無限流動性——任何數量都能以指定價格成交
- 3 種策略模板均為全倉進出（非分批建倉）

### 執行模型

- 信號-執行分離為固定模式：day t 收盤信號 → day t+1 開盤執行
- 不支持日內交易或更高頻率
- 滑價模型為固定比例（不支持市場衝擊模型）
- 佣金為固定比例（不支持階梯式或固定金額）

### 基礎設施

- 資料庫僅支援 PostgreSQL（測試使用 SQLite + 類型映射）
- 無分散式任務佇列（回測同步執行）
- 無快取層
- 無 rate limiting

## 資料限制

### 示範資料性質

Phase 1 的 DEMO-ALPHA、DEMO-BETA、DEMO-BENCHMARK 為確定性生成的模擬資料：

- 不代表任何真實資產
- 不反映真實市場行為
- 價格路徑為預先計算，非隨機生成
- 僅供功能驗證與開發測試

### 資料完整性

- Dataset checksum 可驗證資料未被修改
- 但無法驗證資料的「正確性」——因為是模擬資料
- 遷移至真實資料時需重新驗證所有策略行為

## 產品限制

### 用戶體驗

- 無手機版介面優化
- 無策略視覺化圖表（僅文字/數字展示）
- 無實驗比較功能（不能並排比較兩個回測結果）
- 無策略參數優化（grid search / walk-forward）
- 無研究筆記功能（模型已定義，UI 未實現）

### 協作

- 無團隊共享或協作功能
- 無工作空間管理 UI
- 無實驗分享或公開功能

### 安全

- 密碼使用 bcrypt 雜湊（安全）
- JWT token 無 refresh 機制
- 無雙因素驗證
- 無 session 管理（無法遠端登出）

## 商業風險

### 未驗證假設

Phase 1 並未驗證商業可行性。以下所有假設均為未經市場驗證的內部假設：

1. 目標用戶是否願意為回測工具付費
2. 教育者是否需要團隊功能
3. 用戶是否信任模擬結果
4. 內部曾討論定價假設（個人/教育方案），但均為 **內部試點定價假設 — 非公開定價，未經市場驗證**
5. 一次性工具 vs 持續訂閱的偏好
6. 用戶留存率與支援成本

**Phase 1 不建立商業永續性。** 用戶是否願意付費、是否回流、是否需要經濟上可管理的支援，均未經驗證。

### 競爭風險

- 現有工具（TradingView, QuantConnect）功能更完整
- 免費替代方案眾多
- 差異化價值需進一步驗證
