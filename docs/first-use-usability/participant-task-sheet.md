# 受試者任務單

謝謝你協助測試。這是一個**研究記錄工具**的早期版本，不是投資建議，也不是交易系統。

## 開始之前

- 這裡的資料全部是**合成示範資料**，不是真實市場數據，也沒有真實金錢；任何數字都不代表回報或投資成效。
- 我們測試的是產品，不是你。沒有正確答案，也沒有時間壓力。
- 你可以在任何時候停下來、跳過任何一項，或要求我們不再記錄。
- 登入資料由主持人在開始時提供；不需要你自己找。

## 五項任務

請按主持人的次序做，不需要一次做完。做每一項之前，主持人會先說明那一項的目的。

### A. 找回一次研究

找回你之前做過的一次研究，講出：當時的假設是什麼，以及當時得到的結果或證據是什麼。

### B. 修改一個策略

修改一個你已經有的策略，但**保留原本的版本**，並說出你改了什麼、新舊版本的差異在哪裡，以及你為什麼這樣改。

### C. 判斷能否訓練

判斷你目前為什麼可以、或為什麼不可以訓練個人模型，並指出下一步應該做什麼。

### D. 比較兩個模型

比較兩個模型版本，說出它們的差異，以及這些比較結果在證據上有什麼限制。

### E. 離開再回來

離開系統（登出或關閉頁面），重新登入，然後繼續你之前未完成的工作。

## 請盡量說出聲

- 你現在看到什麼？
- 你以為下一步會發生什麼？
- 有沒有哪個字或數字你看不懂？
- 有沒有任何時候你不確定自己在哪裡？

你不需要使用技術名詞；用你平常的說法就可以。
