## 每項任務（A–E 各一份）

| 欄位 | 填寫方式 |
| --- | --- |
| 任務編號與名稱 | A–E，照任務單 |
| 使用帳號 | 空白／資料不足／已訓練 |
| 無提示下是否完成 | 是／否；只按 L0–L1 |
| 使用過的提示層級 | L0／L1／L2／L3／L4，按發生次序 |

| 參與者原話 | 至少 1–3 句，逐字，不加評語 |
| 是否阻礙主要工作 | 是／否／不確定；說明哪一項研究工作中斷 |
| 主持人備註 | 只在必要時；不寫主觀評分 |

## 填寫規則

1. **先無提示，後提示**：任何提示發生前，先記下已完成到哪裡、停了多久。
2. **提示後完成 ≠ 獨立完成**：只要用了 L2–L4，就標記「提示後完成」並寫明層級。
3. **不補寫**：事後回想的内容要標「會後補充」，與現場觀察分開。
4. **不計分**：不要寫「7/10 分」「滿意度 4/5」或任何主觀評級。
5. **不代入**：不要寫「他應該是想⋯⋯」；寫「他說⋯⋯，然後⋯⋯」。
6. **空白合法**：未觀察到的欄位留空並在備註寫「未觀察」，不要猜。
7. **敏感資料**：不記錄密碼、token、API key；如畫面出現，只寫「畫面顯示了一個憑證欄位」。

## 禁止寫入的內容

- 虛構的訪談、成功率、滿意度、平均完成時間（未實際測量）。
- 把工程走查或 Playwright 結果寫成真人可用性證據。
- 受試者真名、聯絡方式、任何憑證。
- 對受試者能力的主觀評價。

## 保存

- 保存在 owner 指定的本機位置；不上傳、不外傳、不放入公開 repo。
- 若日後要彙總，先確認每位受試者仍同意；彙總只寫觀察與引述，不寫個人身份。
