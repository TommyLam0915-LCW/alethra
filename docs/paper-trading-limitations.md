# Paper Trading Limitations

**版本**: 1.0.0
**日期**: 2026-10-11

---

## 核心聲明

> Paper trading records simulated execution under stated assumptions. It does not reproduce real-money psychology, full market liquidity, partial fills, exchange outages, market impact, or actual brokerage execution.

---

## 1. 執行模型限制

### 1.1 無真實市場流動性

Alethra 的紙上交易使用確定性示範數據（DEMO-ALPHA, DEMO-BETA, DEMO-BENCHMARK）進行模擬成交。此模型：

- 假設任何數量的訂單都能以觀測價格成交
- 不考慮訂單簿深度
- 不考慮市場參與者行為
- 不模擬流動性枯竭情境

**影響**: 在真實市場中，大額訂單可能無法以預期價格成交，或根本無法成交。

### 1.2 無部分成交

系統模擬全數成交或全數拒絕，不支持部分成交：

- 真實市場中，限價單可能只部分成交
- 市價單在極端情況下也可能部分成交
- 部分成交會改變持倉成本和後續決策

**影響**: 用戶可能過度樂觀估計訂單執行能力。

### 1.3 無交易所宕機或延遲

系統假設：
- 所有訂單立即成交
- 無網路延遲
- 無交易所停機
- 無 API 中斷

**影響**: 真實交易中，技術故障可能導致訂單失敗、延遲執行、或無法平倉。

## 2. 價格模型限制

### 2.1 固定滑價模型

滑價使用固定比例（預設 0.1%）：

```
買入執行價 = 開盤價 × (1 + 0.001)
賣出執行價 = 開盤價 × (1 - 0.001)
```

此模型：
- 不考慮市場波動性
- 不考慮訂單大小對滑價的影響
- 不考慮買賣價差（bid-ask spread）
- 不模擬跳空或價格缺口

**影響**: 高波動性或大額訂單的真實滑價可能遠超 0.1%。

### 2.2 固定佣金模型

佣金使用固定比例（預設 0.1%）：

- 不考慮階梯式費率
- 不考慮最低佣金
- 不考慮交易所費用、監管費用
- 不考慮不同經紀商的費率差異

**影響**: 真實交易成本可能與模擬結果有顯著差異。

### 2.3 無市場衝擊

系統不模擬市場衝擊——即訂單本身對價格的影響：

- 大額買入會推高價格
- 大額賣出會压低價格
- 連續訂單會累積衝擊

**影響**: 大額策略的真實表現可能低於模擬結果。

## 3. 心理與行為限制

### 3.1 無真實資金心理

紙上交易不涉及真實資金，因此：

- 無虧損的真實痛苦
- 無獲利的真實喜悅
- 無「賭博」或「恐懼」情緒
- 無資金壓力的決策偏差

**影響**: 用戶在真實交易中可能表現出不同的風險偏好和決策模式。

### 3.2 無時間壓力

系統允許用戶無限時間思考決策：

- 無即時市場變化的壓力
- 無「錯過機會」的焦慮
- 無多任務處理的需求

**影響**: 真實交易需要在有限時間內做出決策，可能導致不同的行為。

---

## 4. 數據限制

### 4.1 示範數據性質

Phase 3B 使用的 DEMO-ALPHA, DEMO-BETA, DEMO-BENCHMARK 為：

- 確定性生成的模擬數據
- 不代表任何真實資產
- 不反映真實市場行為
- 價格路徑為預先計算

**影響**: 策略在真實數據上的表現可能與模擬結果顯著不同。

### 4.2 無即時數據

系統使用歷史快照數據：

- 無即時價格饋送
- 無即時新聞或事件
- 無基本面數據
- 無另類數據

**影響**: 真實交易需要即時數據和持續監控。

---

## 5. 系統限制

### 5.1 無外部經紀商整合

系統明確不包含：

- 經紀商 API 連接
- 交易所 API 連接
- 真實訂單執行
- 真實資金轉移

這是設計決策，確保系統明確定位為研究工具而非交易平台。

### 5.2 無多資產組合

當前版本：
- 每次訂單僅針對單一資產
- 不支持組合層級的風險管理
- 不支持資產配置或再平衡
- 不支持相關性分析

### 5.3 無高級訂單類型

僅支持：
- 市價單（模擬立即成交）
- 限價單（仍模擬立即成交，不等待觸發）

不支持：
- 止損單
- 止盈單
- 追蹤止損
- 條件單
- OCO（One-Cancels-Other）訂單

---

## 6. 合規與法律限制

### 6.1 非投資建議

Alethra 的紙上交易功能：

- 不構成投資建議
- 不構成交易推薦
- 不保證真實交易結果
- 不適合作為真實交易的唯一準備

### 6.2 教育用途

紙上交易主要用於：

- 學習投資研究方法
- 測試策略邏輯
- 追蹤決策行為
- 評估預期與結果的差異

不應用於：

- 預測真實市場表現
- 驗證策略的商業可行性
- 作為真實交易的直接依據

---

## 7. 用戶責任

用戶應理解：

1. 紙上交易結果不代表真實交易結果
2. 模擬盈利不保證真實盈利
3. 模擬虧損不代表真實虧損會更小或更大
4. 真實交易涉及額外風險（技術、監管、流動性）
5. 應在真實交易前諮詢合格的財務顧問

---

## 8. 未來改進方向

以下限制可能在未來版本中解決：

| 限制 | 優先級 | 說明 |
|------|--------|------|
| 真實數據整合 | 高 | 接入付費數據供應商 |
| 高級訂單類型 | 中 | 止損、止盈、條件單 |
| 多資產組合 | 中 | 組合層級風險管理 |
| 更複雜的滑價模型 | 低 | 基於波動性和訂單大小 |
| 部分成交模擬 | 低 | 限價單等待邏輯 |

以下限制為設計決策，不會解決：

| 限制 | 說明 |
|------|------|
| 真實資金心理 | 本質上無法模擬 |
| 外部經紀商整合 | 產品定位為研究工具，非交易平台 |
| 即時數據饋送 | 需要額外的基礎設施和成本 |
