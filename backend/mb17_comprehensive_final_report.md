## 五、統計分析

### 5.1 G5 驗證（Deflated Sharpe Ratio）

**門檻**：|t| ≥ 2.96  
**計算方式**：t = SNR × √trades

**最佳配置**：
- USD/JPY @ 1440min, comm=0.5x
  - SNR = +0.093
  - Trades = 53
  - t = 0.093 × √53 = **0.677**
  - **結論**：FAIL（|t| < 2.96）

**所有配置**：
- 最大 |t| = 0.677（USD/JPY）
- 所有 |t| < 2.96
- **結論**：G5 FAIL（無統計顯著邊）

### 5.2 G6 驗證（放棄條件）

**條件**：所有 commission ≤ 0.002 的 net_pnl ≤ 0 且所有 SNR ≤ 0

**結果**：
- 加密貨幣：所有 net_pnl ≤ 0 ✓
- 股票：AAPL net_pnl > 0 ✗
- 外匯：USD/JPY net_pnl > 0 ✗

**結論**：G6 **未觸發**（股票和外匯有正收益配置）

### 5.3 G7 驗證（折間穩定性）

**計算**：fold SNR 的 stdev

**結果**：
- 加密貨幣：stdev ≈ 0.47（與 MB-14 相似）
- 股票：stdev ≈ 0.35（較穩定）
- 外匯：stdev ≈ 0.25（最穩定）

**結論**：外匯市場比加密貨幣更穩定（stdev 0.25 vs 0.47）

### 5.4 G8 驗證（成本韌性）

**計算**：net_pnl(comm=2.0x) / net_pnl(comm=0.5x)

**結果**：
- 加密貨幣：比值 ≈ 0.85（成本韌性可接受）
- 股票：比值 ≈ 1.20（高佣金反而更好）
- 外匯：比值 ≈ 1.00（成本中性）

**結論**：所有市場成本韌性可接受（比值 > 0.3）
